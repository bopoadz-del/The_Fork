## Re-ingest (ops, after merge)

```bash
# Dry-run census (no writes)
.venv/bin/python scripts/extraction_census.py --out artifacts/EXTRACTION_CENSUS.md

# For every delta>0 row with SOURCE_AVAILABLE, supersede via R1+R3 (does not hard-delete)
.venv/bin/python scripts/extraction_census.py --apply-reingest --out artifacts/EXTRACTION_CENSUS.md
```

`--apply-reingest` calls `add_document(..., reingest_of=<old_id>)` then
`index_document(..., stamp_as_indexed=True)`. Live Neon numbers stay UNPRODUCED
until this is run against production `DATA_DIR`.
