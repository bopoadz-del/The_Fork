## Standards to cover (all of these)

**Model building codes (ICC family):**
- IBC — International Building Code (commercial / multi-occupancy master)
- IRC — International Residential Code (1–2 family dwellings, townhouses)
- IECC — International Energy Conservation Code
- IFC — International Fire Code
- IPC / IMC / IFGC — plumbing, mechanical, fuel gas

**Structural:**
- ASCE 7 — minimum design loads (wind, seismic, snow, live/dead, load combos)
- AISC 360 — structural steel
- ACI 318 — structural concrete
- ASTM — materials/testing (referenced throughout)

**MEP / energy / fire / life-safety:**
- ASHRAE 90.1 — energy standard for commercial buildings
- ASHRAE 62.1 — ventilation / indoor air quality
- NFPA 101 — Life Safety Code
- NFPA 13 — sprinklers
- NFPA 72 — fire alarm & signaling
- NFPA 70 (NEC) — National Electrical Code
- NFPA 30 — flammable & combustible liquids (industrial)
- NFPA 497 / 499 — hazardous (classified) locations (industrial)

**Accessibility:** ADA / ICC A117.1

**Worker safety overlay:** OSHA 1910 (general industry), interface with OSHA 1926 (construction)

## Organize the fill by building use

- **Residential** — IRC-led; IECC residential; ASCE 7 loads; NEC; IPC/IMC. IBC where IRC defers (R-2/R-3/R-4).
- **Commercial** — IBC-led; ASCE 7 / AISC 360 / ACI 318; ASHRAE 90.1 & 62.1; NFPA 101/13/72; ADA / A117.1.
- **Industrial** — IBC F/H/S occupancies; NFPA 30/70/497/499; OSHA 1910; FM Global data sheets; API where process/oil-gas applies.
