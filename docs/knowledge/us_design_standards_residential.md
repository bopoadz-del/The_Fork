## Standards this file covers (residential — R-occupancy, 1–2 family & townhouses)

- **IRC** — International Residential Code (the master for 1–2 family dwellings)
- **IECC** — International Energy Conservation Code (residential provisions)
- **IBC** — R-occupancy provisions where IRC defers to it (R-2/R-3/R-4 multifamily)
- **ASCE 7** — minimum design loads (wind, seismic, snow, live/dead)
- **NEC / NFPA 70** — electrical
- **IPC / IMC / IFGC** — plumbing, mechanical, fuel gas
- Local amendments (state/municipal) — note where they override the model code
