## Codes to cover (all of these)

**Dubai:**
- Dubai Building Code (DBC) — the master for the Emirate of Dubai
- Dubai Green Building Regulations & Specifications (Al Sa'fat)
- Dubai Civil Defence — Fire & Life Safety Code of Practice (UAE FLS)
- Dubai Municipality regulations / circulars

**Abu Dhabi:**
- Abu Dhabi International Building Code (ADIBC) — adaptation of the ICC/IBC family
- Estidama — Pearl Rating System (PBRS / PCRS) sustainability
- Abu Dhabi Civil Defence fire requirements
- DMT / Abu Dhabi Municipality regulations

**Federal / shared:**
- UAE Fire and Life Safety Code of Practice (Civil Defence, federal)
- Relevant referenced base standards (ASHRAE, NFPA, BS EN) — cite, don't reproduce
